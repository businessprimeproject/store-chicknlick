# Shared hosting deployment

1. Create the project locally with Composer and run `composer install --no-dev --optimize-autoloader`.
2. Create a MySQL database and update the `DB_*` values in `.env`.
3. Set `APP_ENV=production`, `APP_DEBUG=false`, and replace `APP_KEY` with the value generated by `php artisan key:generate`.
4. Upload the Laravel application outside the public web directory when possible.
5. Point the domain's document root to the project's `public` directory. Never expose the project root, `.env`, or `storage` directly.
6. Ensure `storage` and `bootstrap/cache` are writable by PHP.
7. Run `php artisan migrate --force` and `php artisan config:cache` over SSH, or run them locally before uploading the generated cache files.

This project has no Vite or npm build requirement. Tailwind is loaded from its CDN in `resources/views/home.blade.php`.
